Privacy Policy - Pixel Pantry Uploader

Last updated: November 26, 2026

1. What this tool is

Pixel Pantry Uploader is a private automation tool used only by the owner of the YouTube channel "픽셀팬트리 | 스팀 특가·추천" (@pixelpantryhq). It uploads videos that the owner creates to the owner's own YouTube channel on a schedule and adds them to the channel's own playlists.

2. YouTube API Services

This tool uses the YouTube API Services. By using this tool you agree to be bound by the YouTube Terms of Service. Information handled through YouTube API Services is also subject to the Google Privacy Policy.

3. Data we access and store

The tool only accesses the owner's own YouTube channel, and only to upload videos and add them to playlists. It does not access, collect, store or share any data about other YouTube users or viewers. No personal data is sold or shared with third parties.

The only stored credentials are the owner's OAuth client ID, client secret and refresh token, kept as encrypted secrets in the owner's GitHub Actions. They are used only to upload videos.

4. Retention and deletion

The tool keeps no user data. The stored credentials are kept only while the tool is in use and are deleted from GitHub when the tool is no longer used. Access can be revoked at any time on the Google security settings page: https://myaccount.google.com/permissions. After access is revoked, the tool can no longer access the channel.

5. Contact

Contact us through the YouTube channel https://www.youtube.com/@pixelpantryhq.
