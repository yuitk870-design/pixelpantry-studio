Privacy Policy - Pixel Pantry Uploader

Pixel Pantry Uploader is a private automation tool used only by the owner of the YouTube channel "픽셀팬트리 | 스팀 특가·추천" (@pixelpantryhq). It uploads videos that the owner creates to the owner's own YouTube channel on a schedule.

The tool uses YouTube API Services. It only accesses the owner's own YouTube channel, to upload videos and add them to the channel's playlists. It does not access, collect, store or share any data about other YouTube users or viewers.

The OAuth credentials are stored only as encrypted secrets in the owner's GitHub Actions and are used only for uploading. No data is sold or shared with third parties.

Use of YouTube API Services is subject to the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy). Access can be revoked at any time at https://myaccount.google.com/permissions.
